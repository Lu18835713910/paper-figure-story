# 全篇研究思路 × 实验路线联合总框架：强制与Figure页区分（最终版）

## 输出定位

- **总框架页只能有一个研究范围：整篇论文**。对应用户参考PPT中的“研究对象—处理/分组—关键测量与作用—进一步验证—收束机制”的版式。参考截图：用户自行提供的参考图（如有）。
- **Figure页仅解释单个Figure/子故事**，把独立提炼的关键文字用上下箭头连接，左边论文Figure是证据载体；不要将它放大来冒充总框架。
- 总图中多种组学技术通常是并行观测同一条件的不同维度；不得默认为“做完RNA-seq才去做ATAC-seq”。

## 总框架页JSON `study_map`

```json
{
  "kind": "framework",
  "title": "研究总体思路与实验路线联合框架",
  "lead": "中心科学问题：……",
  "study_map": {
    "material": {"name": "研究对象", "detail": "样本/组织/模型", "targets": "候选靶点（如有）"},
    "groups": [{"name": "对照组", "detail": "对照条件和时间"}, {"name": "实验组", "detail": "干预/时间点"}],
    "core_assays": [{"name": "测量方法", "purpose": "用本方法回答的具体问题"}],
    "validations": [{"name": "补充证据或功能实验", "purpose": "检验哪项假设、提供何种证据"}],
    "synthesis": "精确且有证据支持的全篇核心结论",
    "note": "关于并行/汇合/证据界限的说明"
  }
}
```

- `groups` 2–4项，`core_assays` 2–4项，`validations` 2–5项。复杂论文拆附加设计细化页，不能缩小文字。
- `validations` 表示“进一步验证/独立证据”模块；描述型、资源型论文可以是独立重复、跨队列对照、外部空间验证，绝不凭空创建RNAi或KO。
- `synthesis` 对机制型论文可以写机制模型；对图谱型论文写总体发现/组织规律，不能强求因果。
- 箭头仅指研究设计、证据关联、进一步检验或证据汇合，不代表分子作用方向，除非原文已有因果支持。

## Figure结果页

逐图 `kind=figure` + `story_steps`（2–7步），每项从原文提炼出动作/结果/解释/下一步。发现项附 `panel_ref`；只在真递进时用实线箭头，并行/比较关系特殊标注。论文原图、坐标/图例与图注来源保留。

## PPT验收强制项

1. 总框架有对象、处理、技术+用途、验证+用途、结果收束；无固定五步箭头。
2. Figure页不是总框架缩略版，左侧原图，右侧逐实验科研逻辑文字链。
3. 任意文字和线条可编辑；原论文Figure本身可为清晰的独立图片。
4. 默认16:9、`#174994`、无Logo；用户指定模板优先。
5. 所有数字、对照、处理、结果对照原文，不把关联改写为因果。
