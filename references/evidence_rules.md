# 事实可靠性与证据分级规则

## 证据来源优先级

1. 原文 Results/Methods 及对应 Figure legends，结合Figure图像和统计图例确认。
2. Supplementary Materials，用于确认对照、样本、实验参数和替代解释。
3. Abstract/Discussion，用于研究目标与整体诠释；需查明相应数据是否真的支撑。
4. 用户既有PPT只用于格式/叙事习惯，不作为事实来源。若与原文冲突，记入核查表。

## 强制核对字段

- Figure原编号 vs PDF页码 vs PPT中的引用编号；注意某些PDF先图后图注、跨页排版。
- 对象：物种/模型/细胞系/组织/年龄/基因型/性别等；仅记原文报告的信息。
- 组别：对照、阳性、阴性、野生型、敲低、剂量、条件、时间点。
- 数值：n到底是细胞、测序样本、供体、组织还是独立动物；排除/纳入标准；生物重复还是技术重复。
- 百分比：分子与分母、条件和比较组。比如“新增解释28%的GWAS信号”和“解释全部GWAS信号28%”不可混淆。
- 统计：P / FDR / PP / 置信区间/阈值，指标之间不得混用。
- 测量：单细胞数据的“细胞相对丰度估计”不等于实测绝对细胞数量。
- 术语：TF motif富集≠直接结合；体外DAP-seq结合潜力≠体内结合；可及性≠转录活性；空间邻近≠配体受体功能通讯。

## 结论措辞词典

| 证据 | 通常可以说 | 不要单凭它说 |
|---|---|---|
| 表达/热图/开放峰差异 | 观察到、与…相关 | 证明…驱动 |
| 富集/聚类 | 富集于、提示分群规律 | 确认直接分子机制 |
| 相关性/共定位 | 关联、支持共享信号假说 | 确定因果变异和靶基因 |
| 轨迹/伪时间 | 推断可能状态连续变化 | 直接证明真实谱系转变 |
| 预测细胞丰度 | 估计细胞组成发生变化 | 绝对细胞数已被测量 |
| 敲低/敲除 | 在该模型中支持必要性 | 唯一原因、普遍充分条件 |
| 过表达/补救 | 支持调控作用/部分救援 | 对所有背景普遍成立 |

## 缺失值处理

- 明确字段但论文未见：`原文未报告（已查Results/Methods/Fig legends）`。
- 尚未完成核查：`待核查：需要查看Supplementary Fig...`。
- 参考PPT有而论文不支持：`参考PPT表述存疑：...；原文支持：...`。
- 科学推断不是作者明说：`报告者推断（非原文直述）：...`。

## 图像使用

- 不改变原始实验图的坐标轴、组别、显著性标记或关键图例。
- 如在PPT重绘示意图，标为“根据论文研究逻辑绘制的示意图”，不得伪装为实验结果。
- 用户明确要求生成PPTX时，优先使用原论文图中对应的panel或明确标注的自制流程示意，处理引用及再使用许可。导出后逐页检查截断、图像清晰度、乱码。
